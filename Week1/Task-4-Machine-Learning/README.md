# Task 4 - Machine Learning Models

This task focuses on implementing and evaluating Machine Learning models using Python and Scikit-learn.

## Objectives

- Prepare a dataset for Machine Learning
- Split data into training and testing sets
- Build a regression model
- Build a classification model
- Make predictions
- Evaluate model performance
- Visualize model results

## Models Implemented

### 1. Linear Regression

Linear Regression was used to predict students' final marks using:

- Study Hours
- Attendance
- Previous Marks

Evaluation metrics:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### 2. Logistic Regression

Logistic Regression was used to classify students into:

- Pass
- Fail

Evaluation metrics:

- Accuracy
- Confusion Matrix
- Classification Report

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Workflow

1. Create and inspect the dataset
2. Check missing values
3. Select features and target
4. Split data into training and testing sets
5. Train Machine Learning models
6. Make predictions
7. Evaluate model performance
8. Visualize results
